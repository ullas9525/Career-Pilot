# MVP Scope

## Philosophy
The Minimum Viable Product (MVP) for CareerPilot is designed to be built within a strict 9-week timeline by a final-year engineering team. The scope is aggressively constrained to features that prove the core thesis: that AI can conduct a hyper-realistic, role-specific technical interview and provide objective, actionable feedback at near-zero marginal cost.

## Included Features

### 1. Student Core Loop
- **Signup / Authentication:** Basic email and password authentication.
- **Role Selection:** Backend Developer, Frontend Developer, Product Manager, Data Science.
- **Resume Parsing & Scoring:** Automatic evaluation of uploaded resumes against the Resume Rubric.
- **Interview Setup:** Input target company and paste Job Description (JD).
- **Live Interview Execution:**
  - Full audio pipeline (STT -> LLM -> TTS).
  - Context generated by DeepSeek v4 flash (via Tavily Search API) using JD + Resume.
  - Live conversation driven by Nematron 3 Nano Omni API.
- **Results & Feedback:**
  - Computation of Career Readiness Score.
  - Side-by-side transcript review (actual vs. ideal answer).
  - Score breakdown against explicit role rubrics.
  - Generation of a 14-day improvement plan.

### 2. Administrator / Coordinator Core Loop
- **Basic Dashboard:** View total interviews conducted and average cohort scores.
- **Student List:** List of students with their computed Career Readiness Scores.
- **At-Risk Alerts:** Basic flagging of students scoring consistently below 4.0.

### 3. Non-Functional Scope
- **Architecture:** Monolithic/Modular Backend (Python/FastAPI) deployed on Render.
- **Database:** Neon serverless PostgreSQL.
- **Cost Target:** Near-zero cost during MVP stage assuming usage remains within free-tier limits.
- **Privacy:** Immediate media deletion post-interview; anonymous leaderboards.

## Excluded from MVP (Deferred to Future Scope)
- LinkedIn / GitHub profile audits.
- Video facial-expression / confidence analysis (avoided for technical/ethical reasons).
- Full anxiety-management module (breathing exercises, real-time anxiety tracking).
- Adaptive Anti-Cheating logic.
- Peer-to-peer mock interviews.
- Multi-language support.
