# User Stories

## Epic 1: Student Onboarding and Profile
- **US1.1:** As a student, I want to create an account using my email so that my progress is securely saved.
- **US1.2:** As a student, I want to select my target role (e.g., Backend Developer) so that the system tailors the interview context to my career goals.
- **US1.3:** As a student, I want to upload/input my resume details so that the AI interviewer can ask me personalized questions about my past projects.

## Epic 2: Mock Interview Execution
- **US2.1:** As a student, I want to input a target company name and paste a Job Description (JD) so that the mock interview simulates the exact role I am applying for.
- **US2.2:** As a student, I want the system to conduct a live voice conversation so that I can practice my verbal communication skills in a realistic setting.
- **US2.3:** As a student, I want the AI interviewer to generate dynamic follow-up questions based on my answers so that the interview feels like a real human interaction, not a static quiz.

## Epic 3: Scoring and Feedback
- **US3.1:** As a student, I want to view a detailed breakdown of my interview performance against objective rubric dimensions so that I know exactly what to improve (e.g., Code Quality vs. System Design).
- **US3.2:** As a student, I want to read the transcript of my interview alongside an "Ideal Answer" generated by the AI so that I can learn how to structure my thoughts better.
- **US3.3:** As a student, I want to see my composite Career Readiness Score (incorporating resume score, interview score, and consistency) so that I can track my overall employability.

## Epic 4: Placement Coordinator Management
- **US4.1:** As a placement coordinator, I want to view an aggregated dashboard of all student mock interviews so that I can assess the overall readiness of the cohort.
- **US4.2:** As a placement coordinator, I want the system to flag students with consistently low Career Readiness Scores so that I can intervene and provide manual mentorship.
- **US4.3:** As a placement coordinator, I want the option to log real-world placement outcomes so that the system can eventually correlate mock scores with actual job offers.
