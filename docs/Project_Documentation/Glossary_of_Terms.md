# Glossary of Terms

To ensure absolute consistency across all documentation, source code, and academic presentations, the following terminology must be strictly adhered to:

## 1. User Archetypes
- **Student:** The primary end-user who utilizes the platform to practice mock interviews.
- **Placement Coordinator:** (Also referred to simply as "Coordinator"). A university administrative user responsible for monitoring the performance of a cohort of students.

## 2. Platform Features & Metrics
- **Mock Interview:** A single, continuous session between a Student and the AI, consisting of multiple conversational turns.
- **Career Readiness Score:** The primary metric generated by the platform. An aggregate score out of 10.0 derived from the `Interview Score` (60%), `Resume Score` (30%), and `Consistency Score` (10%).
- **Live Audio Loop:** The core interactive mechanism of the platform where a student speaks and receives near-instantaneous spoken feedback.

## 3. Technology Stack Definitions
- **Neon:** The serverless PostgreSQL provider utilized for all persistent relational data storage.
- **Render:** The cloud hosting platform utilized for running the backend Python/FastAPI server.
- **Vercel:** The CDN and edge computing platform utilized for hosting the Vite React + JavaScript frontend.
- **Groq:** The ultra-low-latency LPU cloud provider utilized for Speech-to-Text (STT) via the Whisper model.
- **DeepSeek (v4 Flash):** The primary reasoning LLM utilized for heavy background tasks: parsing resumes, generating initial interview context, and conducting post-interview scoring against the rubrics.
- **Nematron (3 Nano Omni):** The extremely fast, conversational LLM utilized *exclusively* during the Live Audio Loop to generate immediate conversational responses.
- **Edge TTS:** The Text-to-Speech API utilized to generate the human-like audio response of the AI interviewer.
- **Tavily:** The AI-optimized Search API utilized to pull real-world, company-specific interview questions from the internet.

## 4. Academic Terminology
- **MVP (Minimum Viable Product):** The Phase 1 iteration of CareerPilot designed strictly to prove the <3.0s latency architecture and validate the core hypothesis at zero marginal cost.
- **B2B (Business-to-Business):** The commercialization strategy where the platform is sold to Universities rather than directly to Students.
- **Golden Dataset:** A static set of pre-recorded transcripts used to regression-test the DeepSeek scoring prompts.
