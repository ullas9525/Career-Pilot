# Phase 2 Expansion Roadmap

Once the core MVP is validated by the pilot program, Phase 2 focuses on expanding the feature set to increase student engagement and provide more value to B2B university clients.

## 1. LinkedIn & GitHub Audits
- **Concept:** Students spend significant time building digital profiles. The AI will cross-reference the uploaded resume with public LinkedIn data and GitHub repository readmes.
- **Value:** Ensures consistency. The system will flag if a student claims "Expert in Vite React" on their resume but has no React projects on their GitHub, preparing them for recruiters who check both.

## 2. Peer-to-Peer Mock Interviews
- **Concept:** A matchmaking system allowing two students to act as Interviewer and Interviewee. The platform provides the Interviewer with the CareerPilot rubric and suggested questions based on the target Job Description.
- **Value:** Deepens understanding. Students often learn as much by evaluating others as they do by being evaluated. This also increases platform engagement without incurring API LLM costs.

## 3. Faculty Dashboards
- **Concept:** Granular analytics for professors. E.g., "70% of the Computer Science cohort failed the System Design portion of the interviews this week."
- **Value:** Allows the university to dynamically adjust their curriculum (e.g., spending an extra week teaching Load Balancers) based on real-time competency data, rather than waiting for placement failures.

## 4. Proprietary Question Banks
- **Concept:** While the MVP relies on Tavily web searches for questions, Phase 2 will introduce licensed or manually curated question banks for top-tier companies (FAANG).
- **Value:** Guarantees absolute accuracy and relevance of the questions asked during the mock interview.
