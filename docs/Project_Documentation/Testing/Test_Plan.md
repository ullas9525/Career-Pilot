# Test Plan

## 1. Introduction
This document outlines the testing strategy for the CareerPilot platform. Given the AI-heavy nature of the application, standard deterministic testing (where output is always exactly the same) must be augmented with heuristic and latency-based testing methodologies.

## 2. Testing Scope
- **In Scope:** Unit testing of backend routing and scoring math, Integration testing of database CRUD operations, E2E testing of the user authentication and resume upload flow, Latency testing of the AI audio loop.
- **Out of Scope (for MVP):** Load testing beyond 100 concurrent users, Cross-browser testing on legacy browsers (IE11), Automated testing of the exact spoken words generated by the AI (due to LLM non-determinism).

## 3. Testing Phases

### Phase 1: Unit & Component Testing
- **Execution:** Automated via GitHub Actions on every Pull Request.
- **Tools:** PyTest (for FastAPI), React Testing Library (for frontend components).
- **Focus:** Validating the Career Readiness Score calculation formula, JWT token generation/validation logic, and RBAC middleware.

### Phase 2: Integration Testing
- **Execution:** Automated via GitHub Actions on merge to `main`.
- **Tools:** TestClient (FastAPI).
- **Focus:** Database interaction (verifying that starting an interview correctly writes a record to Neon PostgreSQL and links it to the user ID).

### Phase 3: AI Pipeline Latency Testing
- **Execution:** Manual during MVP; automated via custom scripts post-MVP.
- **Tools:** Custom telemetry wrappers.
- **Focus:** Verifying that the STT -> LLM -> TTS pipeline consistently completes within the 3.0-second SLA.

### Phase 4: User Acceptance Testing (UAT)
- **Execution:** Manual testing by the internal team and a closed group of 10 beta students.
- **Focus:** Subjective evaluation of the AI's conversational realism, feedback brutality, and overall UX smoothness.
