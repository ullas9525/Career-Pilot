# Data Retention Policies

To comply with GDPR/CCPA and to aggressively manage database storage costs (keeping the MVP within the Neon free tier), CareerPilot enforces strict data lifecycle rules.

## 1. Ephemeral Media (Audio/Video)
- **Policy:** Zero Retention.
- **Mechanism:** Student audio blobs are received by the server, buffered in RAM, streamed to Groq (STT), and immediately purged. Text-to-Speech audio generated by Edge TTS is streamed to the client and purged.
- **Storage:** Media files are never written to the server's persistent disk storage or any cloud buckets.

## 2. PII and User Profiles
- **Policy:** Retained until User Account Deletion.
- **Mechanism:** Students can trigger a "Delete Account" action from their profile. This triggers a `CASCADE` delete on the `users` table, wiping their email, resume data, and all interview transcripts instantly.
- **Coordinator Access:** Placement coordinators lose access to a student's data the moment the student deletes their account.

## 3. Interview Transcripts (JSONB)
- **Policy:** Rolling 12-Month Retention (Scalability Plan).
- **Mechanism:** During the MVP, all transcripts are kept indefinitely (subject to the 0.5GB Neon limit). Post-pilot, an automated CRON job will delete or offload the heavy JSONB `transcript` fields for interviews older than 12 months, retaining only the `career_readiness_score` integer for long-term cohort analytics.

## 4. System Logs
- **Policy:** 30-Day Retention.
- **Mechanism:** Application logs (which contain zero PII) are retained by the hosting provider (Render) or an external log sink for a maximum of 30 days to facilitate debugging, after which they are permanently overwritten.
